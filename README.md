# Revision Hub CS: Cambridge Computer Science code examples

Python and Cambridge-style pseudocode for the standard algorithms in **Cambridge IGCSE Computer Science (0478)** and **Cambridge International AS & A Level Computer Science (9618)**.

Every example is short, commented and runs as it is. Each one links to the matching unit on [revisionhub.online](https://revisionhub.online), where you will find free notes, live tools, self-marking questions and a grade-predicting test.

- IGCSE 0478 course: https://revisionhub.online/igcse-computer-science-0478/
- A Level 9618 course: https://revisionhub.online/a-level-computer-science-9618/
- Free resources for teachers (with classroom mode): https://revisionhub.online/for-teachers/
- Video lessons and 30-second Shorts: https://www.youtube.com/@revisionhubonline

## How to run the Python examples

You need Python 3. Download or clone this repository, open a terminal in the folder and run, for example:

```
python igcse-0478/03_linear_search.py
```

## A note on pseudocode

The pseudocode files follow the style used in Cambridge exams, so you can compare them line by line with the Python versions. In the exam, always follow the pseudocode guide for your syllabus.
