// Validation: range, length, presence and type checks (Cambridge-style pseudocode)
// Notes and practice: https://revisionhub.online/igcse-computer-science-0478/algorithm-design-and-problem-solving/

// Range check with a WHILE loop: OR is used to reject values outside the range
INPUT Mark
WHILE Mark < 0 OR Mark > 100 DO
   OUTPUT "Invalid. Enter a mark from 0 to 100"
   INPUT Mark
ENDWHILE

// Length check
INPUT Password
WHILE LENGTH(Password) < 8 DO
   OUTPUT "Password must be at least 8 characters"
   INPUT Password
ENDWHILE

// Presence check
INPUT Name
WHILE Name = "" DO
   OUTPUT "Name cannot be blank"
   INPUT Name
ENDWHILE
